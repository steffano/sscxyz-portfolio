# sscxyz | Creative Technologist & Engineer

Engineering rhythm-driven visual systems and interactive installations. This is the source code for my personal portfolio, built with a focus on performance, real-time rendering aesthetics, and seamless content management.

## 🚀 Tech Stack

- **Framework:** [Astro 6](https://astro.build/) (SSR on Cloudflare)
- **Frontend:** [React 19](https://react.dev/) & [Tailwind CSS 4](https://tailwindcss.com/)
- **CMS:** [Keystatic](https://keystatic.com/) (Git-based)
- **Deployment:** [Cloudflare Pages](https://pages.cloudflare.com/) & [Wrangler](https://developers.cloudflare.com/workers/wrangler/)
- **Creative Tools:** TouchDesigner, After Effects, GLSL, Cinema 4D
